# 计算机科学基础

欢迎来到计算机科学基础课程。本课程涵盖从 Windows 环境配置、命令行工具、编译器使用，到 Julia 编程语言和 Go 语言入门的完整内容体系。

## 课程内容

### CS 基础
Windows 命令提示符、PowerShell、环境变量、gcc 编译器安装与 CLion、Makefile、静态/动态链接库，以及 SAM、CoolProp 实操案例。

### Julia 入门
Julia 安装与 REPL、语法要点、包管理与环境、类型系统、代码编译（app / library / 系统镜像）、元编程、IJulia、HTTP 服务与 gRPC、前后端分离。

### Go 语言简介
Go 语言安装与核心特性快速入门。
