# Ai4Energy Docs - Computer Science Basics

Ai4Energy 文档 - 计算机基础与语言入门

## 内容

- **CS 基础**: Windows 环境、gcc 编译器、Makefile 等
- **Julia 入门**: Julia 编程语言从入门到精通
- **Go 语言简介**: Go 语言快速入门

## 部署

本项目使用 VitePress 构建，部署在 GitHub Pages：
https://huxinyang-web.github.io/ai4edocs-cs-basics/

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
